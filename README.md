# 🚀 Expo React Native Starter

A modern, high-performance mobile starter template designed for rapid development. This boilerplate bridges the gap between web and native development using the latest industry standards.

---

## 🛠 Tech Stack

| Feature | Technology | Description |
| :--- | :--- | :--- |
| **Framework** | [Expo](https://expo.dev/) | Managed workflow for universal apps. |
| **Navigation** | [Expo Router](https://docs.expo.dev/router/introduction/) | Type-safe, file-based routing (Next.js style). |
| **Styling** | [NativeWind](https://www.nativewind.dev/) | Tailwind CSS utility classes for React Native. |
| **Language** | [TypeScript](https://www.typescriptlang.org/) | Strict typing for enterprise-grade scalability. |
| **Platform** | **Cross-Platform** | Native support for iOS, Android, and Web. |

---

## 🏃 Getting Started

### Prerequisites

Before you begin, ensure you have **Node.js (LTS)** installed. We also recommend installing the **Expo Go** app on your physical device for the best development experience.

### Installation

1. **Clone the repository:**

   ```bash
   git clone <your-repo-url>
   cd <your-project-name>
   ```

2. **Install dependencies:**

   ```bash
    npm install
   ```

3. **Start the development server:**

   ```bash
    npx expo start
   ```

## 📁 Project Structure

```bash
├── app/                # Main application routes (Expo Router)
├── components/         # Reusable UI components
├── assets/             # Images, fonts, and static files
├── hooks/              # Custom React hooks
├── tailwind.config.js  # NativeWind configuration
└── app.json            # Expo configuration
```
